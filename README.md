# Student Record Management System

A Java console-based Data Structures and Algorithms project that manages student records while demonstrating custom implementations of linked lists, stacks, queues, searching, sorting, and hashing.

## Features

- Add and display student records
- Delete records
- Linear search
- Binary search
- Bubble sort by CGPA
- Insertion sort by ID
- Merge sort by name
- Queue-based admission processing
- Stack-based recently removed records
- HashMap-based ID lookup

## DSA Concepts

| Concept | Use |
|---|---|
| Linked List | Main student record storage |
| Stack | Recently removed records |
| Queue | Admission processing |
| HashMap | Fast ID lookup |
| Linear Search | Unsorted search |
| Binary Search | Sorted ID search |
| Bubble Sort | CGPA ordering |
| Insertion Sort | ID ordering |
| Merge Sort | Name ordering |

## How to Run

```bash
javac src/*.java -d out
java -cp out Main
```
